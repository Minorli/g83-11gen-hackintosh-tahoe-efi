# G83 本机维护路线

以下为 2026-11-12 本机巡检的脱敏结论。原始 EFI、硬件身份、认证信息与日志不进入仓库。

## 优先级与验收

| 优先级 | 问题 / 任务 | 现有证据 | 下一验收条件 |
| --- | --- | --- | --- |
| P0 | 图形卡死与闪屏 | BCS busy/hung、多次 GPU 恢复；UU 显示远端画面后闪屏可复现 | 分别定位复制引擎与呈现链路，单项候选通过回归后再做实际远程会话 |
| P0 | WindowServer 内存持续增长 | 独立进程每命令缓冲约 76 KiB；实际 WS 大分配持续增长 | 审查分配所有权与 CPU / GPU 完成时序，完成全局修复及长期曲线验收 |
| P1 | USB 映射 | 主控制器映射 16 逻辑端口，实际只创建 15 个；SS04 未创建 | 逐物理口 USB2 / USB3、Type-C 正反插和内置设备测试后重建映射 |
| P1 | 固定负载功耗 | XCPM 与 X86PlatformPlugin 已附着；操作期间温度报告 46–55°C，Thermal Nominal | 清空旧泄漏后，比较安静桌面 / 浏览 / 远程三个固定场景；不把受采样器影响的数据当待机功耗 |
| P2 | ACPI 与输入 | I2C 实际 Interrupt Mode 为 APIC；全局 `_REG` 重命名范围需核对 | 取得固件 DSDT 及命中数后再限定补丁；不凭参数名称认定触控板在轮询 |
| P2 | 音频与蓝牙 | 驱动与设备枚举存在；TGLDmic Ready，未持续 Streaming | 各路录音、播放 / 耳机切换、蓝牙设备与恢复测试 |
| P2 | 电池 | ACPI 报告约 45% 容量与 CheckBattery | 与固件 / 其他系统交叉确认；不改容量字段掩盖问题 |
| P2 | 睡眠 | 本机未尝试；按继承方案禁用，无当前失败唤醒样本 | 图形稳定、保存工作并准备回退后，单独测试显示熄屏、睡眠、休眠 |
| 延期 | 无线吞吐 | 认证成功；代理和网络环境仍是测速变量 | 同位置同网络做其他设备对照，再分离代理、链路与驱动因素 |

NVMe 当前 TRIM 与 SMART 状态正常，未发现与此次图形故障对应的存储 I/O 失败证据；
不以“缺少某个 kext”为由盲装存储或电源组件。

## 分支与集成规则

- `main`：本机主维护线路，合入已明确边界的配置和文档改进。
- `fix/tahoe-enterprise-wifi`：独立无线贡献分支；不混入图形或整机设置。
- `fix/opencore-config-validation`：可供上游审查的配置结构校验及 I2C 依赖顺序修订。
- 图形源码：独立 WhateverXe-Next 项目。通过审查和实际验收后才集成其二进制。

仓库的公开配置是去身份的集成模板，不是私人启动配置的逐字副本。
每次部署前记录实际差异；格式校验、构建成功、单进程 GPU 测试、整机启动和长期验收分层记录。
保留工作软件、同步、远程工具及有意的镜像布局，不通过批量禁用服务掩盖图形问题。
