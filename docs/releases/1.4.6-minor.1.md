# Dynabook G83 i7-1165G7 开发预发布 1.4.6-minor.1

合入 G83 上游至 `ed57bf0`。模板采用下游 WEX 0.8.2、启用匹配 RTS522A 的 RealtekCardReader 0.9.7，
保留企业认证修订和配置校验。新增 S0ixStandby 0.5.4 与 SSDT-DEEPIDLE，默认关闭，CPUID 保持既有值。

这是仓库集成，没有安装到维护者的活动 EFI。官方 Graphics 0.4.4 Metal / framebuffer 与本机当前文件相同，
不代表闪屏已修复；VA 仍隔离，图形 / 睡眠 / TF 分开验证。完整范围见 [集成记录](../Integration-20261116.md)。

保留独立机器身份、ACPI 与 USB 表；禁止直接以空身份模板覆盖已工作的机器配置。
